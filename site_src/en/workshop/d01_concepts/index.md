## Chinese Source with Bilingual Headings

# D1: Concepts and Decision Framework / D1: 概念 + 决策框架

> 模块类型：纯讨论 / 决策模块 ｜ 时长：45 min（30 讲 / 0 实操 / 15 评审）｜ 凭证要求：无

## Goals / 目标

- 你将能在一张 Foundry 能力地图上指出"我的项目现在在哪一格"
- 你将能针对自己的项目，给出"用 / 不用 / 部分用 Foundry"的明确结论，而不是"再想想"
- 你将能至少说出 4 种"不应该用 Foundry"的场景，并对照到自己手上的项目
- 你将能口头讲清"为什么不选 LangGraph / 不直接用 Azure OpenAI"中至少一条对照
- 你将能识别 4 类常见误判（客户合同 ≠ 技术选型、托管平台 vs 编排库不可比、迁移成本何时产生、Foundry ≠ 锁死 Azure）

## Prerequisites / 前置

- 带一个你自己（或团队）真实在做 / 计划做的 agent 类项目，能用一句话说清业务目标 + 当前阶段
- 通读 plan 第五·五节"Foundry 能力地图"，到课时不需要重新解释每一格是什么

## Subtasks / 子任务

1. [Foundry 能力地图速览](01.md) — 对照五·五节能力地图，定位自己项目落在哪一格
2. [填写"是否用 Foundry"决策卡](02.md) — 用讲师模板当场填自己的项目
3. [评审与反例对照](03.md) — 拿自己的决策卡对照 4 条常见误判自检

## Acceptance Criteria / 验收

学员自检清单（评审段讲师会抽 2-3 份对照）：

- [ ] 决策卡至少勾 1 个"倾向 Foundry" + 1 个"倾向不用 Foundry"维度；若单边成立，已写一句为什么对侧维度全不适用
- [ ] 结论一栏给出明确"用 / 不用 / 部分用"，不是"再想想"
- [ ] 如果结论是"部分用"，能在五·五能力地图上指出至少 2 格
- [ ] "我不确定的地方"一栏非空（承认不确定优于假装全懂）
- [ ] 能口头讲清"为什么不选 LangGraph / 直接 Azure OpenAI"中至少一条对照

## Credential Notes / 凭证说明

纯讨论 / 纯文档模块，无需 Azure 凭证、无需 Foundry project、无需任何 SDK 安装。
