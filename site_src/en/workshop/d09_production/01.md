# D9-01: GH Actions Workflow Walkthrough

> Module: D9 Production Checklist | Credentials: Reading and templates; no real deployment required

## Purpose
Read the workflow and mark critical steps. This step turns the module decision into a concrete learner artifact that can be reviewed during class.

## Instructions
- Compare native Agent Service orchestration, as_tool, and Workflows.
- Use the prepared diff or recording where the alternative path is not run live.
- Write the selected orchestration path and why the other two are rejected.

## Acceptance Criteria
- The requested artifact exists and can be reviewed by the instructor or assistant.
- The artifact uses concrete values from your project rather than generic placeholders.
- Any uncertainty is written explicitly instead of hidden.
- The output remains consistent with earlier decision cards unless you document why the decision changed.

## Submission
- Save the artifact in the matching `submissions/` folder for this step.
- Include short notes, screenshots, logs, or trace links only when they prove the acceptance criteria.

## Common Mistakes
- Writing strengthen monitoring as a fix.
- Sending alerts to an unattended mailbox.
- Assuming startups do not need production discipline.
