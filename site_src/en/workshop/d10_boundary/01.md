# D10-1: 14-Row Capability Domain Overview / D10-1: 14 行能力域速览

> 时长：约 10 min ｜ 凭证：纯阅读，无 Azure ｜ 类型：讲

## Background / 背景
D10 边界表与 plan 第五·五能力地图**镜像**——同 14 行，同顺序。本子任务先把 14 行能力域过一遍，让你知道边界表为什么这么排，不至于在 D10-2 走读时找不到自己关心的那一行。

14 行覆盖：Agent Service / Workflows / Projects / Connections / Identity / Models / Evaluations + Red Team / Tracing + Monitoring / Deployment / Quotas (PAYG) / Capacity (dedicated) / SDK + Agent Framework / A2A / MCP。

## What You Need to Do / 你需要做什么
1. 跟讲师投屏，逐行点名 14 行能力域
2. 在每行旁标记你的项目"用到 / 没用到 / 不确定"
3. 圈出"我项目重度依赖"的 ≤ 3 行——这几行是 D10-4 必填的命中项候选

## Tips / 提示
- 不要纠结"能力域定义边界"——以 plan 第五·五能力地图为准
- "不确定"是合法状态；D10-2 走读后会变清楚
- A2A / MCP 在 plan 标 TODO 是预期内（讲师手册说明）

## Self-Check / 自检
- [ ] 14 行每行都做了"用 / 没用 / 不确定"标记
- [ ] 圈出 ≤ 3 行重度依赖项

## Submission (Counts Toward Capstone) / 提交（计入综合作业）
- 14 行的标记笔记
- 重度依赖 ≤ 3 行清单（带给 D10-4 用）

## Negative Examples / 反例
- "我项目只用 LLM 接口，跟这些都没关系"：通常 Quotas / Capacity / Identity 一定命中，没仔细对
- 跳过没听说的能力域：D10-2 走读会更难跟
