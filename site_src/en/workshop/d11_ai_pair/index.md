# D11: AI-Pair Workflow

> Module type: decision + workflow | Duration: 35 min | Credentials: None; MCP demo depends on Day-7 validation

## Goals
- Turn specs, negative examples, decision cards, and runbooks into team assets.
- Understand the Foundry MCP server path and the Learn URL fallback path.
- Copy a practical spec-library structure into the learner team context.

## Prerequisites
- D2 decision card and D10 boundary table are complete.

## Subtasks
1. [Walk Through the Spec Library Structure](01.md) - Understand README, decision-cards, implementation, negative-examples, and runbooks.
2. [Read Two Example Specs](02.md) - Review new-agent launch and new-provider onboarding specs.
3. [Foundry MCP Server Experience or Fallback](03.md) - Watch the live MCP demo or learn the URL/docs/evidence prompt workflow.
4. [Copy the Directory Structure for Your Team](04.md) - Create or screenshot the starter structure and governance note.

## Acceptance Criteria
- Learner can explain the five directories.
- Learner proposes one improvement to an example spec.
- Learner captures the structure in a team-accessible place.

## Credential Notes
None; MCP demo depends on Day-7 validation.

## Common Mistakes
- Calling an unreviewed wiki a spec library.
- Making specs so rigid that AI has no judgment space.
- Letting the negative-example library only grow and never be reviewed.
