# D11: AI-Pair Workflow / D11: AI-pair 工作流

> 35 min（25 讲 / 0 实操 / 10 评审）· Day 3 午饭后开场 · 无 Azure 凭证要求

## Goals / 目标
- 把 spec + negative example + decision card 接入团队工作流，让 AI-pair 不再是个人小聪明
- 知道 Foundry MCP server 可用性的两种工作流（现场连接 / Learn URL 替代）

## Prerequisites / 前置
- D2 决策卡、D10 边界表完成

## Subtasks / 子任务
1. [spec 库结构走读](01.md) — README / decision-cards / implementation / negative-examples / runbooks
2. [示例 spec 阅读 ×2](02.md) — 新 agent 上线 spec + 新 provider 接入 spec
3. [Foundry MCP server 体验或替代](03.md) — Day-7 由讲师二选一定死：现场连接 demo / Learn URL + SDK docs + portal evidence 喂 AI
4. [给自己团队抄一套目录结构](04.md) — 截图/抄到团队文档，回去当下周起点

## Acceptance Criteria / 验收
- 能复述 spec 库 5 个目录的用途
- 能在示例 spec 上指出 1 处"如果改成 X 会更好"
- 能把目录结构截图或抄到团队文档（不强制 git push）

## Credential Notes / 凭证说明
- Foundry MCP server：讲师 Day-7 验证可用性，决定走"现场连接"还是"Learn URL 替代工作流"
- 学员侧：阅读 + 截图，无需 Azure
