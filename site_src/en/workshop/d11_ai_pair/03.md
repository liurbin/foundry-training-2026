# D11-3: Foundry MCP Server Experience or Fallback / D11-3: Foundry MCP server 体验或替代

> 时长：约 7 min ｜ 凭证：取决于讲师 Day-7 验证结果 ｜ 类型：讲

## Background / 背景
让 AI 知道 Foundry 当前能力，最直接是接 Foundry MCP server。但 MCP 在 rebrand 期、server 可用性会变。**讲师 Day-7 二选一定死**，本子任务跟着走即可：

- **走法 A — 现场连接 demo**：讲师在 Claude/Cursor 里现场打开 Foundry MCP server，演示 AI 直接读 Foundry 文档
- **走法 B — Learn URL 替代工作流**：讲师演示"把 Learn URL / SDK docs / portal evidence 喂给 AI"的手动 prompt 模板

不论哪条，目的相同：让 AI 不在"我猜 Foundry 应该……"上发挥。

## What You Need to Do / 你需要做什么
1. 看讲师当天走的是 A 还是 B（开场会明示）
2. 若是 A：
   - 看 MCP server 在 Claude/Cursor 里怎么挂上
   - 看一个真实 prompt 怎么走通（AI 是直接读到 Foundry 当前能力的）
3. 若是 B：
   - 抄 prompt 模板的骨架（输入：Learn URL / SDK docs / portal evidence；输出：边界结论或实现建议）
   - 学会"喂证据再问"的工作流
4. 不论 A/B，记下你回去能立刻用的 1 条 prompt 模板

## Tips / 提示
- A 不通时 B 就够用——B 不是降级，是稳态备份
- MCP 现场连不上不阻塞 D11 验收（讲师手册 D11 验收 checklist 末条明示）
- 别在 MCP server 部署细节上发问——D11 不是 MCP 教学

## Self-Check / 自检
- [ ] 知道当天走的是 A 还是 B
- [ ] 抄下了 1 条可立刻用的 prompt 模板
- [ ] 理解 A 不通时 B 怎么走

## Submission (Counts Toward Capstone) / 提交（计入综合作业）
- 1 条 prompt 模板（一段即可）

## Negative Examples / 反例
- 因为现场没 MCP server 就说 D11 无用：B 路径同样能落地
- 抄了 MCP 配置细节但没抄 prompt 模板：本子任务的资产是 prompt，不是配置
