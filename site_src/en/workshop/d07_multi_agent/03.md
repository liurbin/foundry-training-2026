# D7-3: 对照路径 B —— Workflows 录屏

> 时长：约 15 min ｜ 凭证：无（看录屏，不需要 portal 访问） ｜ 类型：讲

## Background / 背景

Workflows 是 visual designer 编排路径。本步看讲师准备的 10-15 min 录屏（含一次完整运行 trace），不要求自己进 portal 操作。目标：说出 1 个适用场景 + 1 个不适用场景，不被"看起来最强大"诱导。

## What You Need to Do / 你需要做什么

1. 看完讲师提供的 Workflows 录屏（10-15 min），含 visual designer 操作 + 一次完整运行 trace。
2. 写下来：
   - 1 个适用场景（提示：复杂分支 / 长时间运行 / 非工程师可视化）
   - 1 个不适用场景（提示：80% 简单编排）
3. 如果你最终决策卡里要选 Workflows，必须额外回答"为什么不用主路径或 as_tool 解决"。

## Tips / 提示

- "Workflows 看起来最强大" 是 handbook 反例 1——学习曲线 + 运维复杂度都比另外两条高。
- 录屏里 visual designer 这一段重点看"分支节点 / 长任务节点"——这是它的差异化能力所在。
- 课后想自己玩 → 需要 Foundry portal 权限，不在本课要求内。

## Self-Check / 自检

- [ ] 录屏完整看完（visual designer + 运行 trace 两段都看了）
- [ ] 写出 1 个适用场景（含理由）
- [ ] 写出 1 个不适用场景（含理由）
- [ ] 若决策卡要选 Workflows：额外回答了"为什么不用主路径 / as_tool"

## Submission (Counts Toward Capstone) / 提交（计入综合作业）

- 适用场景 + 不适用场景各 1 条（合计 ≤ 200 字）

## Negative Examples / 反例

- "Workflows 看起来最强大所以选 Workflows" → 学习曲线 + 运维复杂度（handbook 反例 1）
- 适用场景只写"复杂场景" → 太空，要写具体业务特征
- 没看完录屏就选 Workflows → 不接受
