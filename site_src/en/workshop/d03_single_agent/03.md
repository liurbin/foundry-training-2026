# D3-3: Enable and Verify Tracing / D3-3: tracing 启用与验证

> 时长：约 25 min ｜ 凭证：有订阅学员自验；无订阅看讲师演示 ｜ 类型：讲师演示 + 学员对照清单

## Background / 背景
- 第 2 步代码跑通后，本步去 portal 看这一次调用的 trace
- 借鉴上游 Ex04 tracing 启用路径
- Day1 上午讲师已统一确认 project 是否接入 Application Insights / tracing 开关；未启用则本步转可选，留到 D5/D9

## What You Need to Do / 你需要做什么
1. 在 Foundry portal 打开 Monitoring → Traces
2. 找到第 2 步那一次调用（按时间戳 / agent_id 过滤）
3. 对照下面清单逐项确认（X/Y/Z 由讲师当堂指定，下面是示例项）：
   - [ ] 看到顶层 span，duration 与你本地观察的延迟一致
   - [ ] 看到 token 计数（input / output）
   - [ ] 看到 model invocation 子 span
   - [ ] 看到 tool call 节点（若 agent 配了 tool）
4. 截图保存（带 span 树展开状态）
5. 无 tracing 学员：跟讲师演示走，拿一份截图做参考，对照官方文档把清单写出来即可

## Tips / 提示
- 找不到 trace 别急着说"没生效"，先核对 Application Insights 是否真接上（Day1 上午讲师确认过）
- tracing 未启用不是你的锅，留到 D5/D9 补；现在不要花 30 分钟 debug
- Token 计数对 D5 成本估算有用，留意一下

## Self-Check / 自检
- [ ] portal 能定位到本次调用 trace（启用则必做；未启用则跳）
- [ ] 清单 X/Y/Z 三项至少有 2 项能讲出"我看到什么"
- [ ] 截图保存
- [ ] 能口头讲清"换 region 后 trace 上报会有什么变化"

## Submission (Counts Toward Capstone) / 提交（计入综合作业）
- 产物：trace 截图 + 一段对照清单的观察笔记（每项 1 行）
- 放：`submissions/d3_3_tracing/`

## Negative Examples / 反例
- 看到 trace 就勾完，不展开 span 不看 token —— 等于没看
- 因为 tracing 没启用就卡住不做 D4/D5 —— spec 明示此项可选
- 把 trace 链接直接贴出来不写观察 —— "贴链接 ≠ 验证"
