# D3-02: Run a Single Agent

> Module: D3 Single-Agent Platform Path | Credentials: Azure subscription with Microsoft Foundry on Azure project access for real deployment; mock or instructor endpoint for fallback

## Purpose
Call the deployed or mocked agent once and capture logs. This step turns the module decision into a concrete learner artifact that can be reviewed during class.

## Instructions
- Generate the minimum call code for the selected SDK language.
- Use environment variables or Key Vault references for endpoint and agent identifiers.
- Run one successful call or use the approved mock/shared endpoint fallback.
- Inject one controlled error and confirm 429 or 5xx logging is visible.

## Acceptance Criteria
- The requested artifact exists and can be reviewed by the instructor or assistant.
- The artifact uses concrete values from your project rather than generic placeholders.
- Any uncertainty is written explicitly instead of hidden.
- The output remains consistent with earlier decision cards unless you document why the decision changed.

## Submission
- Save the artifact in the matching `submissions/` folder for this step.
- Include short notes, screenshots, logs, or trace links only when they prove the acceptance criteria.

## Common Mistakes
- Deploying AI-generated Bicep without reading the diff.
- Hardcoding model deployment names or secrets.
- Writing retry logic in this step instead of leaving retry strategy for D5.
