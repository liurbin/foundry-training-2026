# Learner Precheck Checklist

## Required Local Tools
- Python 3.10 or later.
- Git.
- curl or an equivalent HTTP client.
- A working AI coding assistant such as Claude Code, Codex, or GitHub Copilot.

## Optional Cloud Access
An Azure subscription is optional for learners. Real Microsoft Foundry on Azure
portal and deployment steps are instructor-led unless learners bring their own
environment.

## Before Class
- Clone the repository.
- Run the precheck script if provided by the instructor.
- Prepare one real or planned agent project to use in decision cards.
- Confirm you can edit Markdown and run local Python examples.

## What to Bring
Bring project context: business goal, target users, expected traffic, compliance constraints, provider preferences, and production concerns.
