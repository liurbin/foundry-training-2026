> 35 min（25 讲 / 0 实操 / 10 评审）· Day 3 午饭后开场 · 无 Azure 凭证要求

## 目标
- 把 spec + negative example + decision card 接入团队工作流，让 AI-pair 不再是个人小聪明
- 知道 Foundry MCP server 可用性的两种工作流（现场连接 / Learn URL 替代）
