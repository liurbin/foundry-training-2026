# D9-5: Azure DevOps 对照 GH Actions 差异

> 时长：约 10 min ｜ 凭证：阅读讲师对照表 ｜ 类型：讲

## 背景
你团队大概率已经在 Azure DevOps 或 GH Actions 之一上有存量。D9 不强推某一条，但你必须**选定一条**并把选择理由写进 D9-6 的 checklist 应用清单。

## 你需要做什么
1. 看讲师投屏的"Azure DevOps 对照 GH Actions 差异表"（讲师手册 D9 → 讲师准备段）
2. 对照三项差异重点：
   - YAML 语法 + task 生态（Azure DevOps task vs GH Actions action）
   - secrets / service connection 管理（Azure DevOps service connection vs GH OIDC + federated credential）
   - 与 Azure 资源的集成成熟度（哪一条对 Bicep / Container Apps 摩擦更小）
3. 在三项里挑出"对你团队最关键的那一项"
4. 写出你团队选哪条 + 一句话理由（写进 D9-6 应用清单）

## 提示
- 不要选"两条都不用、自己搭"——本课不评估这种选择
- 已有存量是合理的选择理由（"团队已经在 ADO，不切")，但要明示存量在哪
- D9-2 的红队 gate 草稿要能在你选的这条上落地

## 自检
- [ ] 三项差异每项都能口头说 1 句对比
- [ ] 已选定一条 + 有理由
- [ ] D9-2 红队 gate yaml 能在你选的这条上跑（不需要真跑，能映射 task 即可）

## 提交（计入综合作业）
- 选择 + 理由（一行）

## 反例
- 选"两条都用"：维护两套 = 都不维护
- 理由写"GH Actions 更新潮"：与团队/项目无关的理由不算
- 选 ADO 但 D9-2 红队 step 还是 GH Actions yaml：未落地
