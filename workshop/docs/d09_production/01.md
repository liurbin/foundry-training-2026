# D9-1: GH Actions workflow 走查

> 时长：约 15 min ｜ 凭证：只读 workflow 文件，无需 Azure ｜ 类型：讲

## 背景
D9 的生产化 checklist 里 CI/CD 段最容易被空话糊弄。先借 Ex05 的 workflow 骨架做一次走查——你不必真跑，只要能在 yaml 上指出关键步骤在哪、为什么这么排。

## 你需要做什么
1. 打开讲师投屏（或自己 fork 仓库）里的 GH Actions workflow 文件
2. 标注出以下关键步骤分别在 yaml 的哪一段：
   - 触发条件（push / PR / 手动 / 定时）
   - 构建 + 单测
   - Bicep diff（人审之前）
   - 部署到 dev / staging / prod 的拆分
   - 回滚动作（有没有？没有的话本步骤补一行 TODO 给 D9-2 用）
3. 找出 workflow 里**还没有红队 gate**的位置——这是 D9-2 要接入的点

## 提示
- 不要求真跑；workflow 走 dry-run / skip deploy 步骤也可以
- 学员可自己 fork 试跑，但不需要 Azure 凭证
- 走查目的是熟悉骨架，不是评审 yaml 质量

## 自检
- [ ] 能在 yaml 上指出 5 个关键步骤的位置（触发 / 构建 / diff / 部署 / 回滚）
- [ ] 能指出红队 gate 应当接在 yaml 哪一段（PR check / pre-deploy / post-deploy 三选一）

## 提交（计入综合作业）
- workflow 走查笔记（截图 + 5 处标注即可）
- 红队 gate 待接入位置标注（给 D9-2 用）

## 反例
- 想着"反正不真跑"扫一眼就过：D9-2 接红队时不知道往哪挂
- 纠结 yaml 语法细节：本步骤目的是结构，不是语法
